Saya Abraham. Kebanyakan yang saya bikin itu **tooling keamanan web** — recon,
pendeteksi webshell, dan assessment upload/SQL injection — plus beberapa aplikasi
web dan API. Yang bikin saya betah ngulik: gimana aplikasi web itu "pecah", dan
gimana cara nemuinnya dengan cara yang aman dan punya izin. Semua tool di sini
dibikin buat kerjaan yang terotorisasi: mendeteksi dan mendokumentasikan, bukan
nerobos.
