### Halo

Panggil aja Bram. Saya suka ngulik keamanan aplikasi web — kebanyakan waktu
saya habis buat bikin tools recon/scanner, aplikasi web, sama API kecil, terus
dibongkar lagi kalau ada yang bisa dibikin lebih rapi. Lagi fokus di tooling
keamanan (recon, deteksi webshell, assessment upload & SQLi) dan belajar bikin
yang beneran bisa dipakai, bukan cuma jalan sekali.

Prinsipnya satu: tools-nya buat kerjaan yang **ada izinnya** — mendeteksi dan
mendokumentasikan, bukan nerobos.
