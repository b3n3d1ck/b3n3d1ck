### `~/about`

Bikin bot, aplikasi web, dan API kecil-kecilan, lalu dibongkar lagi tiap ada yang bisa dibikin lebih rapi. Belakangan banyak main di sisi keamanan web: scanner, audit, deteksi penipuan. Kalau ada yang berhubungan dengan otomasi atau keamanan, biasanya saya tertarik.
